# Қорған жаттықтырушысы

Дене өлшеміңе (бой, салмақ, қол құлашы, аяқ ұзындығы) бейімделген анимациялық жаттықтырушы. Фигура сенің пропорцияңнан құрылады, қашықтықтар сантиметрмен есептеледі.

## Бөлімдер

- **Техникалар** — өзін-өзі қорғаудың 20 техникасы және дене құрылысыңа сай «ойын жоспары» (4 стиль).
- **×1000** — «бір жаттығуды мың рет» қағидасы: әр мақсатқа бір жаттығу, мың қайталау санағышы және 5 деңгей.
  - Көше: қоршау позициясы, алақан соққысы, итеру тебісі, қорғаныс қақпағы, жерден тұру, бас құшақтаудан шығу, жеке қаруың.
  - Күш: отжимание, присед, тартылу, жамбас көпірі, аяқ көтеру, берпи.
  - Икемділік: аяқ сермеу, тізерлеп созылу, алға еңкею, терең присед, қол айналдыру.
- **Раунд таймері** — 2–3 минуттық раундтар, гонг, техника 30 секунд сайын ауысады.
- **Бүйірден / алдынан** көрініс.

## Іске қосу

Бір файл, тәуелділік жоқ: `index.html`-ді браузерде аш.

### GitHub Pages арқылы жариялау

1. GitHub-та репозиторий → **Settings → Pages**.
2. **Source: Deploy from a branch**, branch `main`, папка `/ (root)` → **Save**.
3. Бір-екі минуттан кейін сайт `https://<username>.github.io/qorgan/` мекенжайында ашылады.

## Деректер

Мың қайталау санағышы браузердің `localStorage`-інде сақталады (тек сол құрылғыда). claude.ai Artifact нұсқасында ол аккаунтқа жеке сақталады.

## Ескерту

Анимация жаттықтырушыны алмастырмайды. Жұптық жаттығуды тек қорғаныс құралымен және баяу қарқыннан баста. Қажетті қорғаныс ҚР Қылмыстық кодексінің 32-бабымен реттеледі — қорғаныс шабуылға сай болуы керек.
